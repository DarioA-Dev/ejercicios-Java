# Programación (Java)

Ejercicios y tareas de la asignatura de Programación, ordenados por bloques en el orden en que se han ido viendo en clase.

- Las carpetas que empiezan por `tarea-` son **tareas oficiales de Teams**. Su archivo principal lleva el enunciado original del profesor al principio, como comentario.
- El resto son **prácticas de clase**: se hicieron durante las clases y su enunciado no está escrito en Teams.
- Cada carpeta de ejercicio es un proyecto independiente (tiene su `.project` y `.classpath`), así que se puede ejecutar por separado.

## Añadir un ejercicio nuevo

1. Elige el bloque (o crea uno nuevo con el número siguiente, p. ej. `08-...`).
2. Crea la carpeta del ejercicio con el script (desde la carpeta `Java/`):

   ```powershell
   .\nuevo-proyecto.ps1 programacion\07-arrays\03-tarea-nueva
   ```

   En VS Code también se puede hacer con `Ctrl+Shift+P` → *Tasks: Run Task* → *Java: nuevo proyecto*.
3. Si es una tarea de Teams, pon el nombre `NN-tarea-<titulo>` y copia el enunciado al principio del archivo en un comentario `/* ... */`.
4. Los ejercicios propios van en `90-practicas-personales/` y los de origen dudoso en `99-pendientes-de-identificar/`.

## Compilar y ejecutar desde la terminal

```
cd 05-ejercicios-combinados/02-tarea-temperaturas
javac Temperaturas.java
java Temperaturas
```

En VS Code basta con abrir el archivo y pulsar *Run* encima del `main`.
