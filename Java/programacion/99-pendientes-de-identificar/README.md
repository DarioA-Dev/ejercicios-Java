# Pendientes de identificar

Ejercicios que no corresponden a ninguna tarea de Teams y de los que no está claro si se mandaron en clase o se hicieron por cuenta propia. Estaban todos en la antigua carpeta `TAREAS-REPASO`. No tienen enunciado.

Cuando se sepa de dónde viene uno, se mueve a su bloque (o a `90-practicas-personales`).

| Carpeta | Archivo | Qué hace | Nombre antiguo |
|---|---|---|---|
| `condicionales/` | `PedirNota.java` | Dice si una nota es aprobado o suspenso | `pedirNota.java` |
| `condicionales/` | `CompararNumeros.java` | Dice cuál de dos números es mayor | `repaso.java` |
| `bucles/` | `PedirContrasenaHastaCero.java` | Pide una contraseña numérica hasta acertar o meter 0 | `pedirNumHasta0.java` |
| `bucles/` | `InvertirNumero.java` | Da la vuelta a un número | `Numero_al_reves.java` |
| `bucles/` | `CalcularSumaCifras.java` | Cuenta y suma las cifras de un número | `calcularSumaCifras.java` |
| `bucles/` | `CalificarNotas.java` | Pasa notas a Suspenso/Bien/Notable... hasta meter una negativa | `registrosNotas.java` |
| `incompletos/` | `SupermercadoCuenta.java` | Sin terminar | `supermercadoCuenta.java` |
